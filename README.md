# 🐆 LEOPARD | Urban Agility

High-end, immersive shoe brand landing page featuring smooth animations, interactive 3D-like effects, and an AI-powered styling assistant.

![Leopard Brand](https://images.unsplash.com/photo-1542291026-7eec264c27ff?q=80&w=1000&auto=format&fit=crop)

## ⚡ Features

- **Immersive Visuals**: Fluid background gradients and grain overlays for a premium brutalist aesthetic.
- **Dynamic Collection**: Interactive product cards with unique hover states and depth effects.
- **LEO AI Assistant**: An AI-powered concierge built with Gemini flash models to help users find their perfect pair.
- **Smooth Navigation**: Framer Motion powered scroll transforms and page transitions.
- **Custom Experience**: Tailored custom cursor and interactive UI elements.

## 🛠 Tech Stack

- **React 19**: Modern functional components and hooks.
- **Tailwind CSS**: Utility-first styling with custom theme configurations.
- **Framer Motion**: High-performance animations and layout transitions.
- **Lucide React**: Clean, consistent iconography.
- **Google Gemini API**: Powering the LEO AI assistant for real-time conversation.
- **Vite**: Ultra-fast build tool and development server.

## 🚀 Getting Started

1. **Clone the repository**
2. **Install dependencies**: `npm install`
3. **Environment Setup**:
   Create a `.env` file and add your Gemini API Key:
   ```env
   GEMINI_API_KEY=your_api_key_here
   ```
4. **Run Development Server**: `npm run dev`
5. **Build for Production**: `npm run build`

## ⚙️ CI/CD

This project is configured with **GitHub Actions** for automatic deployment to GitHub Pages. On every push to the `main` branch, the site is built and deployed.
